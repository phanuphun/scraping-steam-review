# Steam Reviews Scraper
This project is created to learn how to use socket.io and Puppeteer for scraping data (game reviews on Steam).<br>
The number of reviews is limited to 10,000. Simulate means turning on and off chromium to simulate a browser page to scrape data.<br><br>
